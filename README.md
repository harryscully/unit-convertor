# Unit Convertor 📐🧲🧭

A simple vanilla JavaScript app that converts between metric and imperial units.

**Live demo:** https://harryscully.github.io/unit-convertor/

## Features

- Enter a number and instantly convert across three unit types:
  - **Length:** metres ↔ feet
  - **Volume:** litres ↔ gallons
  - **Mass:** kilograms ↔ pounds
- Results displayed to 3 decimal places

## Built with

- HTML
- CSS
- JavaScript
